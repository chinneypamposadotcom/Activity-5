# Clothify — ACT-05 Hero Section

This project recreates the user's Figma hero-section reference as a responsive HTML/CSS webpage.

## Files
- `index.html` — page structure and navigation
- `style.css` — styling, Flexbox, Grid, and responsive breakpoints
- `assets/hero-fashion.jpg` — cropped fashion photograph from the supplied Figma screenshot

## Run locally
Open `index.html` in a browser, or open the folder in VS Code and use Live Server.

## Notes
The logo is recreated with styled text and CSS because a separate logo asset was not supplied. The hero photograph is cropped from the screenshot provided by the user. Google Fonts are loaded online; a network connection is needed for those fonts.
